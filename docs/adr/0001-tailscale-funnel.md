# 0001 公開方法に Tailscale Funnel を使う

## 背景

自宅のサーバーに置いたファイルを、自宅の外にいる仲間が受け取れるようにしたい。
Discord に添付できるのは 10MB まで(ブーストなし)で、zip のやり取りには足りない。
そのため、大きなファイルは https の URL で受け渡す必要がある。

## 決定

Web は `127.0.0.1` でだけ待ち受け、Tailscale Funnel で `https://<マシン名>.<tailnet名>.ts.net` として公開する。
Bot と Web は 1 つのプロセスで動かす。

## 選ばなかった案

- Cloudflare Tunnel: 独自ドメインが必要(年 1500 円ほど)。導入する人の手間も増える。
- ルーターでのポート開放: 自宅の IP が見え、証明書や攻撃への対策を自分で持つ必要がある。
- 仲間を tailnet に招待する: 全員に Tailscale を入れてもらう手間がかかる。

## 結果

- ドメイン・ポート開放・証明書の管理がいらない。受け取る側は何も入れなくてよい。
- 公開されるのは Funnel で指定したポートだけで、SSH などは閉じたまま。
- Funnel の帯域には上限があり(値は非公開)、大きなファイルが続くと遅くなりうる。
- ダウンロード用 URL を知っていれば誰でも落とせる。URL を推測できない長さにして補う。
